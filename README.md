Uma aplicação de análise de dados financeiros construída com **Python** e **Streamlit**, projetada para transformar dados brutos em insights visuais claros e interativos.

## Sobre

Este projeto utiliza a biblioteca **Streamlit** para criar um painel web dinâmico e o **Pandas** para o processamento e manipulação de dados financeiros. O objetivo é demonstrar a capacidade de gerar visualizações estratégicas e filtros em tempo real a partir de conjuntos de dados.

## Funcionalidades

- **Visualização Dinâmica:** Gráficos interativos de evolução de receitas e despesas.
- **Filtros Personalizados:** Seleção de períodos (meses) via barra lateral.
- **Métricas de Performance:** Cálculo automático de totais com indicadores visuais.
- **Interface Intuitiva:** Layout limpo e responsivo focado na experiência do utilizador.

## Stack Tecnológica

- **Linguagem:** Python 3.10+
- **Framework Web:** Streamlit
- **Processamento de Dados:** Pandas
- **Gráficos:** Gráficos nativos do Streamlit (Altair/Plotly)
